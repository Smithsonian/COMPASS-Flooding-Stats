The data release contains biomass data. The data itself is housed in nine separate .csv files which can be joined by the transect and/or plot attributes. 

site_coordinates.csv - Contains positional information on site locations.
plant_species_cover - Contains information on the plant cover at sampling locations.
other_evironmental_cover.csv - Contains cover of bare ground, leaf litter, standing dead, open water and wrack.
harvested_biomass.csv - Contains harvested biomass information from sampling locations.
Phragmites_allometry.csv - Contains allometry information for Phragmites australis.
Iva_allometry.csv - Contains allometry information for Iva frutescens.
other_species_allometry.csv - Contains allometry information for species other than Phragmites and Iva.
all_biomass.csv - Contains derived biomass for all years, transects, plots, and species
plant_species_codes - Contains information on the dominant plant species at sampling locations.

metadata.xml - Contains a full suite of descriptive metadata with all attribute and variables defined, units clarified, and geographic, temporal, and taxonomic coverages described according to Ecological Metadata Language Standards.

metadata.html - Is a simplified, visual and interactive version of metadata.xml for display purposes.

map.html - Is a map widget showing the geographic coverages described in the metadata. It can be accessed on its own or through metadata.html.

custom.css - Contains display information for metadata.html.
